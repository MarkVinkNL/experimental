# Crosses

Animated rotating cross grid, based on a sketch by [Okazz](https://openprocessing.org/user/184331).

## Debug / Settings

Append `#debug` to the URL to open the settings panel:

```
index.html#debug
```

Available settings:

| Setting     | Description                                   |
| ----------- | --------------------------------------------- |
| Loop Time   | Duration of one full animation cycle (frames) |
| Cell Count  | Number of cross columns/rows in the grid      |
| Cross Width | Stroke width multiplier                       |
| Background  | Background color                              |
| Cross Color | Default cross color                           |
| Palette     | 9 accent colors used by the crosses           |
| Restart     | Manually restart the animation                |
